Controls

VR

Left stick: move · Right stick: turn
Trigger: collect, use, place, throw
Grip: grab / hold · A: jump

Keyboard & mouse

WASD: move · Mouse: look · Space: jump · Shift: run
Left click: collect, use, place, throw
E: grab · Right click / F: remove / get off
R: change color · Esc: release mouse
